Fy-api 主流模型接入文档

面向客户开发者和平台运营的统一接入指南：客户按协议调用，运营按渠道接入，所有模型通过 TraceNex 网关完成鉴权、路由、计费和日志追踪。

1 个 Base URLOpenAI SDK 填 /v1，其他协议按端点调用。
9 类协议Chat、Responses、Claude、Gemini、Image、Video、Audio、Embedding、Rerank。
异步任务视频、Midjourney、Suno 需要提交任务后轮询查询。

快速开始

本文不是厂商原生 API 文档。它说明的是客户如何通过 Fy-api 统一接入模型，以及管理员如何把模型接入平台。页面中的模型名优先作为示例，最终可用模型以平台模型广场和管理员分配为准。

快速结论：文本、图片、Embedding、Rerank、语音转文字通常是同步接口；Chat / Responses / Claude / Gemini 可按模型能力选择同步或流式；视频、Midjourney、Suno 是异步任务，先提交，再按 task id 查询。

准备平台地址

客户拿到部署域名，例如 https://api.example.com。OpenAI 兼容 SDK 的 base_url 通常填 https://api.example.com/v1。

创建令牌

在“令牌管理”创建 sk-... 令牌。令牌可绑定分组、额度、过期时间、模型权限和 IP 白名单。

确认模型名

model 必须与模型广场或管理员提供的名称一致。错误模型名通常会导致 400 或无可用渠道。

curl -X POST https://api.example.com/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "Hello Fy-api"}]
  }'
客户使用场景优先接口说明
OpenAI SDK{BASE_URL}/v1优先调用 /v1/chat/completions，图片、语音、Embedding 也按 OpenAI 兼容接口走。
Anthropic SDKPOST /v1/messages保留 Claude 原生 messages、system、tools、thinking 语义。
Gemini 原生POST /v1beta/models/{model}:generateContent使用 contents / parts 结构，可使用 Gemini 流式路径。
视频生成POST /v1/videos提交后返回 task_id，查询 GET /v1/videos/{task_id}，下载 GET /v1/videos/{task_id}/content。
查询模型GET /v1/models / GET /v1beta/models查看当前令牌可见的模型，具体取决于平台权限配置。
客户报错时请同时提供请求时间、模型名、端点、HTTP 状态码、响应错误和 X-Oneapi-Request-Id。管理员可在用量日志按 request_id 查询。

协议参数

OpenAI Chat Completions

适合大多数文本对话、多模态图片理解、工具调用、JSON 输出和流式输出。

必填：model必填：messagesstreamtemperaturetop_pmax_tokenstoolsresponse_formatreasoning_effort

OpenAI Responses

适合 Responses 协议模型、Codex 类模型、新版工具和多模态工作流。必填 model 与 input，常用 instructions、tools、reasoning、stream。

Claude Messages

适合 Anthropic SDK 或 Claude 原生语义。必填 model、messages；常用 max_tokens、system、stream、temperature、tools、thinking。

高级字段如 context_management、speed、service_tier、inference_geo 默认可能被过滤，只有管理员允许后才会透传。

Gemini Native

适合 Google Gemini 原生 SDK。使用 contents / parts 结构，支持 systemInstruction、generationConfig、safetySettings、tools、toolConfig。

Image

必填 model 和 prompt。常用 n、size、quality、response_format、image、images、mask、watermark。

Video Task

视频生成是异步任务。提交后拿到 task_id，再查询任务状态，完成后取 /v1/videos/{task_id}/content 或响应中的 URL。

参数说明
prompt提示词
image / image_tail图生视频首图 / 尾帧图，按模型支持情况使用
reference_urls阿里 wan2.6-r2v* 推荐参考素材字段
media新版参考素材数组，可含 type、url、reference_voice
duration / seconds时长，单位秒
size / resolution尺寸或分辨率，如 1280*720、720P
audio / watermark是否生成音频、是否加水印，取决于模型支持
metadata厂商特有参数透传

Embedding 与 Rerank

Embedding 使用 model + input；Rerank 使用 model + query + documents。Rerank 可选 top_n、return_documents。

调用示例

流式 Chat

curl -N -X POST https://api.example.com/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "写一个 Go HTTP server 示例"}],
    "stream": true,
    "stream_options": {"include_usage": true}
  }'

Claude Messages

curl -X POST https://api.example.com/v1/messages \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-5",
    "max_tokens": 1024,
    "system": "你是代码审查助手。",
    "messages": [{"role": "user", "content": "请审查这个函数是否有并发问题。"}]
  }'

Gemini Native

curl -X POST "https://api.example.com/v1beta/models/gemini-2.5-pro:generateContent" \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
    "contents": [{
      "role": "user",
      "parts": [{"text": "解释一下 RAG 的基本流程"}]
    }],
    "generationConfig": {"temperature": 0.4, "maxOutputTokens": 1024}
  }'

图片生成

curl -X POST https://api.example.com/v1/images/generations \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-1",
    "prompt": "一张专业的 API 网关架构图，深色背景",
    "size": "1024x1024",

管理员接入流程

  1. 准备厂商账号、API Key、Base URL、模型名、模型能力、价格规则。
  2. 进入管理员后台 -> 渠道管理 -> 添加渠道。
  3. 选择渠道类型，填写名称、分组、密钥、Base URL、模型列表、测试模型。
  4. 配置模型权限、模型价格、分组倍率和令牌权限。
  5. 用低成本模型先跑健康检查，再验证正式模型。
  6. 检查用量日志是否有 usage、费用、request_id 和错误信息。
视频模型建议单独建 video-only 分组，价格按秒、分辨率或任务档位配置。上线前必须验证提交、查询、完成、下载和失败退款。

排障

问题可能原因处理
401 UnauthorizedToken 错误或过期重新创建令牌
403 Forbidden模型无权限、分组无权限、IP 白名单不匹配检查令牌权限和用户分组
400 model is required请求体缺少 model补模型名
400 field messages is requiredChat 请求缺少 messages使用 Chat schema
400 contents is requiredGemini 原生请求缺少 contents使用 Gemini schema
429 Too Many Requests限流或余额不足保护降低频率、检查额度
视频一直 in_progress上游生成慢或轮询延迟按 5s、10s、20s、30s 退避轮询
流式没有 usage渠道不支持 stream_options.include_usage以平台用量日志为准

限制与建议

  • /v1/files、fine-tunes、图片 variations 等部分 OpenAI 端点当前未实现。
  • 同名参数是否生效取决于模型和上游渠道，网关负责接收和尽力转换。
  • 高级字段可能被管理员配置过滤，防止不兼容或额外计费。
  • 视频、Midjourney、Suno 等任务类接口必须按任务查询。
  • 价格展示和实际扣费以后台价格、模型倍率、分组倍率和任务实际用量为准。
